# Security policy

## Scope

This repository contains analysis instructions and helper scripts. It does not
contain malware, target binaries, or exploit code.

## Responsible use

- Use the skill only on software you own or are authorized to test.
- Run unknown binaries only in an isolated VM or sandbox.
- Do not use the skill to bypass licensing, DRM, authentication, activation, or
  anti-cheat systems.
- Do not upload live samples to public services without explicit approval.
- Redact credentials, tokens, personal data, and customer data from reports.

## Reporting a problem in this skill

Open a private security advisory or contact the maintainer with:

- the affected file;
- a minimal reproduction;
- the potential impact;
- a suggested fix, if available.

Do not include live malware samples in an issue.
